# 嵌入式硬件与软件学习笔记

个人学习电子硬件和嵌入式软件的笔记合集。每篇都是一个独立的 HTML 文件，图都是内嵌的 SVG，下载后双击用浏览器打开就能看，不依赖网络。

**在线阅读：<https://andyblog.github.io/embedded-notes/>**

> 在 GitHub 仓库页面直接点开 `.html` 只能看到源码，请用上面的在线地址阅读，或者克隆到本地用浏览器打开。

## 说明

- 笔记中的数值例子多为说明原理的典型值或估算值，实际设计请以器件规格书和实测为准。
- 涉及 220V 市电的内容请注意安全：断电、放电、确认后再操作，调试使用隔离变压器。
