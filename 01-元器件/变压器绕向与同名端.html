0. 先记住四句话

① 电压看同名端：任何时刻，所有绕组的同名端（带黑点的一端）电压极性相同，同时为正或同时为负。
② 电流"进初级的点，出次级的点"：电流从初级同名端流进去时，次级（接了负载、电流能流通的话）电流从次级同名端流出来。
③ 变压器只传"变化"：次级电压由磁通的变化产生。交流一直在变，所以一直有输出；直流只在接通、断开的瞬间有输出，稳定后次级是 0V。
④ 电感电流不能突变：直流断开时，线圈为了维持原来的电流，所有绕组电压立刻反向，而且可能很高。这就是开关电源里的反激电压和尖峰。

1. 电生磁、磁生电：三个定则和楞次定律

变压器的所有方向判断，都来自电磁学里的两件事：电生磁（电流产生磁场）和磁生电（变化的磁场产生电压）。另外还有一件相关的事：磁场对电流有力（电动机的原理）。三件事各有一个"手"的定则，很容易记混：

现象定则怎么比划典型应用
电生磁
电流 → 磁场		右手螺旋定则
（安培定则）		直导线：右手握住导线，大拇指指电流，四指弯曲方向就是磁感线方向。
线圈：右手握住线圈，四指顺着电流绕向，大拇指指的是 N 极（线圈内部磁通方向）		电磁铁、继电器、变压器初级、电感
磁生电
导体切割磁感线		右手定则
（发电机定则）		伸开右手，磁感线垂直穿入手心，大拇指指导体运动方向，四指就是感应电流方向发电机、电机反电动势
磁生电
线圈里磁通变化		楞次定律
+ 右手螺旋定则		感应电流产生的磁通，总是反对原磁通的变化：原磁通增加，它就反着来；原磁通减少，它就顺着补。再用右手螺旋定则从"它要的磁通方向"反推电流方向变压器次级、辅助绕组、电感关断尖峰
磁场对电流有力左手定则
（电动机定则）		伸开左手，磁感线垂直穿入手心，四指指电流方向，大拇指就是受力方向电动机、喇叭、电流表指针
防混口诀："左力右电"——左手判断力（电动机），右手判断感应电流（发电机）。"右手螺旋"是另一个，判断电流产生的磁场，手是"握"着的，不是伸开的。
在变压器里最常用的是右手螺旋定则 + 楞次定律：初级用前者（电生磁），次级用后者（磁生电）。右手定则是楞次定律在"导体切割磁感线"时的简便用法，两者结论一致。

1.1 电生磁：右手螺旋定则

1.2 磁生电：右手定则，和反过来的左手定则

1.3 磁生电：楞次定律（线圈里最常用）

经典实验：磁铁插入、拔出线圈，线圈接一个电流表。

法拉第电磁感应定律：  e = − N · dΦ/dt
  N      ：匝数，匝数越多电压越大（所以变压器电压比 = 匝数比）
  dΦ/dt  ：磁通变化得越快，电压越大（所以断开瞬间电压很高、频率越高变压器可以越小）
  负号    ：就是楞次定律，感应电压的方向反对磁通变化

1.4 放到变压器里看

常见东西用到的原理
继电器、电磁铁、电磁阀电生磁（右手螺旋定则判断 N 极）；断电时线圈磁生电产生反向高压，所以要并联续流二极管
变压器、电感、开关电源电生磁 + 磁生电（楞次定律）
发电机、自行车发电花鼓、电机刹车能量回收磁生电（右手定则）
电动机、喇叭、硬盘磁头臂磁场对电流的力（左手定则）
电机转动时的反电动势转子导体切割磁感线（右手定则），方向和外加电压相反，所以电机转速越高电流越小、卡死时电流最大
电磁炉线盘交变磁场在锅底感应出涡流（楞次定律）发热
无线充电发射线圈电生磁，接收线圈磁生电，就是一个"空心、松耦合"的变压器
电流互感器、霍尔传感器前者是磁生电（变压器原理测交流）；后者是磁场对运动电荷的力（和左手定则同源）

2. 绕向和同名端

常见的 EI、EE、PQ 磁芯，三个线圈都绕在中柱的同一个骨架上。电流流过线圈产生磁通，方向用右手螺旋定则（见第 1 节）：四指顺着电流绕的方向，大拇指指的就是线圈里磁通（N 极）的方向。

同名端的定义：电流分别从两个绕组的某一端流进去，如果产生的磁通方向相同，这两端就是同名端，原理图上用黑点标出。最直观的判断：绕向相同的线圈，起绕端互为同名端。

实际拿到一个变压器，看不到绕向，就看规格书或骨架上的引脚标记（常标 "•"、"S" 起绕、"F" 结束），或者用第 7 节的方法测出来。

3. 交流电：电压极性和电流方向

为什么电流是"进初级点、出次级点"

次级接上负载后有电流 Is，它产生的磁通会抵消初级的磁通（楞次定律：感应电流总是反对引起它的变化）。为了保持磁芯里的磁通不变（磁通由电压决定），初级会自动多吸一份电流补回来。所以：

安匝平衡：  Np × Ip(负载部分) = Ns × Is + Na × Ia
功率守恒：  Vp × Ip ≈ Vs × Is + Va × Ia   （降压变压器：次级电压低、电流大）

"抵消"意味着次级电流在线圈里的绕向和初级相反，换成端子说法，就是初级电流进同名端时，次级电流从同名端出来。

另外还有一个很小的励磁电流：即使次级空载，初级也有一点电流用来建立磁通，它落后电压 90°，不传递功率。空载变压器摸起来微热、有嗡嗡声就是励磁和铁损。

4. 直流电：接通、保持、断开

用一节电池、一个开关、一个变压器就能演示（次级接一个指针电压表或者 LED + 电阻）。

阶段初级电流各绕组电压（同名端）次级电流（接了负载时）原因
① 接通瞬间从 0 开始上升同名端为正，大小按匝比从次级同名端流出磁通增加，感应电压阻碍它增加
② 稳定导通不变（= 电压 / 电阻）0V没有磁通不变就没有感应电压。变压器不传直流
③ 断开瞬间迅速降到 0同名端为负，非同名端为正，电压很高从次级非同名端流出磁通减小，线圈要"维持"电流，电压反向
断开时为什么电压很高：V = L·di/dt。开关一断，电流在微秒内降到 0，di/dt 极大。匝数多的线圈用一节 1.5V 电池也可能在断开时感应出几十到上百伏，手同时捏着两根线会有明显电击感。继电器线圈要并联续流二极管、开关电源要有 RCD 吸收，都是为了这个电压。

理想情况：电感（低电阻）接直流

上面的电池实验线圈电阻较大，电流很快稳定。开关电源里线圈电阻很小、导通时间只有几微秒，电流来不及稳定，一直线性上升（di/dt = V/L），所以整个导通期间各绕组电压都是恒定的：Vs = Vin × Ns/Np，同名端为正。如果导通太久，电流涨到磁芯饱和，电感量骤降，电流失控——这就是开关电源必须限制导通时间的原因。

5. 开关电源里：正激和反激的接法

把电池和开关换成 Vin 和 MOS 管，次级接上二极管和电容，同名端的接法就决定了能量什么时候送出去。

关断时次级电流从非同名端流出，看起来和第 0 节第②句"出次级的点"相反。这不矛盾：第②句说的是初级正在通电流的同时次级的电流方向（正激、交流都是这种）。反激里初级和次级轮流通电流，关断时初级已经没电流了，次级电流是磁芯放能产生的，方向由"磁通要维持不变"决定：它在磁芯里产生的磁通和初级导通时同向，所以从非同名端流出。

6. 串联、并联、中心抽头

两个绕组并联（为了加大电流）必须同名端对同名端，而且电压要一样。接反等于把两个绕组短路，变压器会迅速发烫甚至烧毁。接之前先按第 7 节的方法确认，或者先串联测一下是 24V 还是 0V。

7. 怎么测同名端

安全：测试用的交流必须是低压（如另一个变压器输出的 6~12V），不要把 220V 直接加到不明变压器上做实验。方法一用匝数多的绕组时，断开瞬间会有高压，手不要同时碰两根线；电池正负接在匝数少的绕组上、表接匝数多的绕组，指针摆得更明显。数字表反应慢，用指针表或示波器更好看。

规律一句话
右手螺旋定则四指沿电流绕向，大拇指 = 线圈内磁通方向
右手定则导体切割磁感线（发电机）：磁感线穿手心，大拇指 = 运动方向，四指 = 感应电流
左手定则通电导体在磁场中受力（电动机）：磁感线穿手心，四指 = 电流，大拇指 = 受力
楞次定律感应电压/电流总是反对磁通的变化（磁通增加时反对增加，减少时反对减少）
法拉第定律每匝感应电压 = 磁通变化率，所以电压比 = 匝数比
安匝平衡Np·Ip ≈ Ns·Is（次级电流越大，初级电流越大）
伏秒平衡开关电源稳态时，绕组电压的正面积 = 负面积，否则磁芯逐渐饱和

9. 问答

Q：同名端和绕向是什么关系？
绕向相同时起绕端互为同名端；一个绕组反着绕，或者把它两根引线对调，它的同名端就换到另一头。
Q：变压器能不能接直流？
不能长期接。直流只在接通、断开瞬间有输出；稳定后次级 0V，初级电流只受线圈电阻限制，会很大，烧线圈或者磁芯饱和。
Q：为什么断开时电压反而更高？
V = L·di/dt。接通时电流慢慢涨（受电阻和电感限制），断开时电流在极短时间内降到 0，变化率大得多。
Q：反激和正激的变压器有什么区别？
接法上只是次级同名端在上或在下。设计上反激变压器要储能（开气隙），正激变压器只传能（不开气隙，但要复位磁芯）。
Q：辅助绕组为什么和次级同相？
在反激里它们都要在 MOS 关断时导通：次级给输出供电，辅助给芯片供电，所以同名端接法一样，电压按匝比成正比。也因此芯片能通过辅助绕组电压间接感知输出电压（OVP）。
Q：次级接反会怎样？
交流整流电路：一般没影响（整流桥不在乎相位），但多个绕组串、并联时会出问题。开关电源：反激接成正激，电路无法正常工作，可能炸管。
Q：右手螺旋定则、右手定则、左手定则怎么区分？
"左力右电"：左手判力（电动机），右手（伸开）判感应电流（发电机）；右手"握"住的是螺旋定则，判断电流产生的磁场。变压器主要用右手螺旋定则 + 楞次定律。
Q：楞次定律一句话？
感应电流总是阻碍磁通的变化：增加时反着来，减少时顺着补（来拒去留）。
Q：电流方向和电子方向？
本文说的都是常规电流方向（从正到负），和电子实际移动方向相反，判断同名端时不用管电子。
