1. 为什么要开关电源：LDO 和 DC-DC

常见组合：DC-DC 先把电压降到接近目标值，再用 LDO 稳出干净的电压（如 12V → Buck → 3.6V → LDO → 3.3V 给 ADC），兼顾效率和噪声。

2. 核心规律：电感伏秒平衡

所有开关电源都靠电感（或变压器）储能。第一份笔记讲过：稳态时电感两端"电压 × 时间"的正面积必须等于负面积，否则电流会一直涨（饱和）或一直降。用这一条就能推出每种拓扑的电压公式：

拓扑开关导通 D·T 时电感电压开关关断 (1−D)·T 时电感电压伏秒平衡结果
BuckVin − Vo−Vo(Vin−Vo)·D = Vo·(1−D)Vo = D · Vin
BoostVinVin − VoVin·D = (Vo−Vin)·(1−D)Vo = Vin / (1−D)
Buck-Boost（反相）Vin−|Vo|Vin·D = |Vo|·(1−D)|Vo| = Vin · D/(1−D)，极性相反
FlybackVin（初级）−Vo·Np/Ns（反射）Vin·D = (Np/Ns)·Vo·(1−D)Vo = (Ns/Np) · Vin · D/(1−D)

另一条对偶规律是电容安秒平衡：稳态时电容的平均电流为 0。由它可以推出电感平均电流（Buck 里等于输出电流，Boost 里等于输入电流）。

3. Buck 降压

电路和两个状态

波形

电感纹波电流     ΔI  = (Vin − Vo) · D / (f · L)          （一般取 Io 的 20%~40%）
电感峰值电流     Ipk = Io + ΔI/2                          （电感饱和电流 Isat 要大于它，留余量）
输出电压纹波     ΔV ≈ ΔI / (8 · f · Cout) + ΔI · ESR       （MLCC 的 ESR 很小，电解电容 ESR 占主导）
输入电容电流有效值 Icin ≈ Io · √(D·(1−D))                  （D=0.5 时最大，约 Io/2）

计算例：12V → 5V / 2A，500kHz

D    = 5 / 12 ≈ 0.42
ΔI   取 30% × 2A = 0.6A
L    = (12 − 5) × 0.42 / (500k × 0.6) ≈ 9.7µH  → 选 10µH
Ipk  = 2 + 0.3 = 2.3A                        → 电感 Isat ≥ 3A
Cout = 22µF MLCC：ΔV ≈ 0.6 / (8 × 500k × 22µ) ≈ 6.8mV（加上 ESR 和直流偏压容量下降，实际取 2×22µF）
Cin  有效值电流 ≈ 2 × √(0.42 × 0.58) ≈ 1A   → 输入电容要能扛 1A 纹波电流

同步 Buck：用 MOS 管代替二极管

· 多相 Buck：电脑 CPU/显卡供电（约 1V、几百安）用 6~20 相 Buck 并联，每相错开相位工作，纹波互相抵消，每相只负责几十安。主板上 CPU 旁边一排电感和 MOS 就是它，常说的"几相供电"指的就是这个。
· Buck 的弱点：上管短路时 Vin 直接加到输出，会烧掉后面的芯片，所以重要场合输出要加过压保护。

4. Boost 升压

电感平均电流 = 输入电流 Iin = Io / (1 − D)       （理想；实际再除以效率）
电感纹波电流 ΔI = Vin · D / (f · L)
开关管、二极管承受电压 ≈ Vo

计算例：锂电池 3.7V → 5V / 1A（充电宝），1MHz

D    = 1 − 3.7/5 = 0.26
Iin  = 1 / 0.74 ≈ 1.35A，按 90% 效率约 1.5A（电池电流比输出大）
ΔI   取 30% × 1.5A ≈ 0.45A
L    = 3.7 × 0.26 / (1M × 0.45) ≈ 2.1µH → 选 2.2µH，Isat ≥ 2.5A
电池电压掉到 3.0V 时：D = 0.4，Iin ≈ 1.85A，电感和开关管按这个最坏情况选
Boost 的三个坑：
① 关不断：开关不工作时，输入经电感、二极管直接通到输出（Vo ≈ Vin − 0.5V）。输出短路时没法限流，电流只受电池内阻限制。需要"真关断"芯片或额外加负载开关。
② 不能空载乱升：反馈断开（FB 引脚虚焊）时占空比拉满，输出可能升到几十伏烧坏电容和负载，要加 OVP。
③ 右半平面零点（RHP zero）：负载突然加大时，Boost 要先加大占空比，结果关断时间变短、送到输出的能量反而先减少，电压先往下掉再回升。所以 Boost 环路带宽不能做太高，动态响应比 Buck 慢。Buck-Boost 和反激也有同样的问题。

5. Buck-Boost 升降压

5.1 反相 Buck-Boost（经典型）

用途：从正电源得到负电压，例如给运放提供 −5V、LCD 负压。缺点是输出反相，开关管和二极管要承受 Vin + |Vo|。

5.2 四开关 Buck-Boost（同相，现在最常用）

典型场景：输入电压范围跨过输出电压。锂电池 3.0~4.2V 输出 3.3V；车载 PD 充电器 9~16V 输入要输出 5~20V；充电宝的双向 PD 快充（电池 7.4V，输出 5V 或 20V，还要反过来给电池充电）。

5.3 SEPIC（了解即可）

SEPIC 用两个电感（或一个耦合电感）加一个串联电容，实现同相升降压，输出 Vo = Vin · D/(1−D)。优点是只需要一个开关管、输入电流连续、输出能真正关断；缺点是元件多、效率比四开关低。常见于 LED 驱动和汽车电子。

6. Flyback 反激：带变压器的 Buck-Boost

反激比 Buck-Boost 多了什么说明
电气隔离220V 进、手机端出，初次级之间只有磁耦合，这是安规要求
匝比Vo = (Ns/Np)·Vin·D/(1−D)。310V → 5V 不需要极小的占空比，靠匝比先降下来
多路输出多绕几个次级就有多路电压，辅助绕组给芯片供电就是一路
漏感两个绕组耦合不完美，关断时有尖峰，需要 RCD 或有源钳位

完整的反激电路分析、启动、反馈、EMI 见 LD7575 学习笔记；氮化镓准谐振反激见 GaN 快充学习笔记。

正激家族：Buck 加上变压器得到正激（Forward），再演变出推挽、半桥、全桥，350W 工业电源的输出级（变压器 + 整流 + 输出电感）就是一个 Buck。这样所有常见拓扑都可以归到两大家族：Buck 家族（正激、半桥、全桥、LLC 的输出侧近似）和 Buck-Boost 家族（反激）。

9.1 CCM、DCM、BCM

9.2 轻载模式：PWM、PFM、跳脉冲

重载时芯片固定频率 PWM；轻载时为了省电改为 PFM（降频）或 Burst（打一串停一会儿），效率高但纹波变大、频率不固定，可能落到音频范围导致电感啸叫。芯片常有 MODE 引脚可以强制 PWM（FCCM）。给音频、射频供电时选强制 PWM。

9.3 控制方式

方式原理特点
电压模式输出电压误差放大后和锯齿波比较得到占空比结构简单，抗噪声好，补偿复杂（LC 双极点）
峰值电流模式电感电流达到误差放大器给的门槛就关断（LD7575 就是这种）逐周期限流，补偿简单；D>50% 要斜率补偿
COT / 恒定导通时间输出低于基准就打一个固定宽度的脉冲负载跳变响应极快，CPU 供电常用，频率略变

9.4 环路稳定性

  • 反馈环路要有足够的相位裕度（一般 ≥ 45°），否则负载变化时输出振荡。
  • 环路带宽一般取开关频率的 1/10~1/5（Boost 还要低于 RHP 零点）。
  • 没有网络分析仪时，最实用的测试是负载阶跃：用电子负载在 10%↔90% 之间跳，看输出电压的过冲和振铃。振荡次数多说明相位裕度不够。
  • 芯片规格书一般给出推荐的补偿元件（COMP 引脚 RC），先照抄。很多新芯片内部已经补偿好。

9.5 元件选型

元件要看的参数和坑
电感饱和电流 Isat（超过后电感量骤降，电流冲高）＞峰值电流并留余量；温升电流 Irms＞有效值电流；DCR（直流电阻，决定铜损）。屏蔽型电感 EMI 小。功率电感不要用色环电感、磁珠代替
输出电容MLCC 直流偏压效应：一颗 10µF/10V 的 0805 电容加 5V 后可能只剩 3~5µF，看厂家的 DC bias 曲线。电解电容 ESR 大、寿命受温度影响
输入电容Buck 的输入电流是脉冲，输入电容承受很大的纹波电流（约 Io/2），要靠近芯片放，MLCC 为主

9.7 测纹波的正确方法

  • 示波器开 20MHz 带宽限制，AC 耦合，探头 ×1 或 ×10。
  • 去掉探头的长地线夹，用探头附带的接地弹簧，探头尖和弹簧直接顶在输出电容两端。长地线夹会形成环形天线，测到大量开关尖峰，看起来纹波好几百 mV，其实是测法问题。
  • 纹波（开关频率的三角波）和噪声（开关瞬间的尖峰）要分开看。

9.8 其他常用知识点

知识点说明
自举（Bootstrap）同步 Buck 上管是高边 NMOS，栅极要比 SW 高约 5V。BOOT 引脚接一个 0.1µF 电容到 SW，下管导通时充电，上管导通时把栅极"抬"上去。这个电容漏焊，芯片会完全不工作
电荷泵只用开关和电容，没有电感。倍压、反相、手机快充里的 2:1 电荷泵（效率 97% 以上，配合 PPS 直充）
软启动上电时让输出慢慢升，避免冲击电流把输入电源拉垮，SS 引脚接电容调时间
EN、PG、UVLO使能、电源正常输出、欠压锁定。多路电源用 PG 串起来做上电顺序
最小导通时间24V → 1V、2MHz 时 D≈4%，导通只有 20ns，可能低于芯片最小导通时间而无法稳压。高降压比要降低频率或两级转换
效率曲线规格书都会给"效率 vs 负载"曲线：轻载看静态电流和轻载模式，重载看导通电阻和电感 DCR
热设计小封装芯片靠 PCB 散热，底部散热焊盘要打过孔连到地平面
EMI输入加 π 型滤波（电容-电感-电容），频率选择避开敏感频段，扩频（展频）功能能降低峰值

10. 设计流程与工具

  1. 明确指标：输入范围（最低、典型、最高）、输出电压和电流、纹波要求、效率、体积、成本。
  2. 选拓扑（第 7 节决策图）。
  3. 选芯片：用厂家的选型工具和在线设计工具（TI WEBENCH Power Designer、ADI LTpowerCAD、MPS、矽力杰等），输入指标直接给出原理图和元件值。
  4. 按规格书典型应用电路核算电感、电容（第 3、4 节的公式）。
  5. LTspice 仿真（ADI 的芯片自带模型，其他厂家很多也提供）：看启动、负载跳变、纹波。
  6. 画 PCB：照抄规格书推荐布局（第 9.6 节）。
  7. 实测：先限流上电 → 测输出电压 → 纹波（第 9.7 节）→ 效率 → 负载阶跃 → 温升 → 短路保护。
动手练习建议（配合工作间规划里的设备）：
① 买一块 LM2596 模块和一块 MP1584 模块，同样 12V→5V/1A，对比效率、发热、纹波，用示波器看 SW 点波形和电感电流（串小电阻测）。
② 用 MT3608 把 3.7V 升到 12V，逐步加负载，观察电池电流比输出电流大多少，以及效率怎么变化。
③ 自己用立创 EDA 画一块同步 Buck 小板，照规格书布局，嘉立创打样，对比好布局和故意画差的布局的纹波。

11. 问答速查

Q：三个基本公式？
Buck Vo=D·Vin；Boost Vo=Vin/(1−D)；Buck-Boost |Vo|=Vin·D/(1−D)。都由电感伏秒平衡推出。
Q：为什么 Buck 输入电流比输出电流小？
功率守恒：Vin·Iin ≈ Vo·Io/效率。降压就是"电压换电流"。Boost 正好相反，电池电流比输出电流大。
Q：同步整流有什么好处？
用 MOS 代替续流二极管，低压大电流时损耗从几瓦降到零点几瓦。需要死区防直通，上管要自举驱动。
Q：Boost 为什么不好做短路保护？
开关关着时输入经电感和二极管直接连到输出，短路电流没有开关能切断。
Q：反激和 Buck-Boost 的关系？
反激就是把 Buck-Boost 的电感换成变压器，多了隔离和匝比。
Q：锂电池供 3.3V 用什么？
电池 3.0~4.2V 跨过 3.3V：要求不高用 LDO（电池低于约 3.4V 后跟着掉）；要用尽电量用四开关 Buck-Boost。
Q：电感选多大？
先定纹波电流（输出电流的 20~40%），再按公式算 L，最后确认饱和电流大于峰值电流。
Q：为什么测出来纹波特别大？
多半是用了探头的长地线夹。换接地弹簧、开 20MHz 带宽限制再测。
Q：轻载时电感吱吱响？
芯片进入 PFM/Burst，频率掉进音频范围。改强制 PWM 模式，或换屏蔽、灌封电感。
Q：MLCC 为什么实际容量不够？
直流偏压效应：加电压后容量大幅下降，小封装、高容值最明显。选更高耐压或更大封装。
