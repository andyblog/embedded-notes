1. 先看全貌：三方各管什么

最重要的一句话：Type-C 只是一个插头的形状。老接口长得不一样，插不进去就知道拿错了；Type-C 什么都插得进去，能不能用要插上才知道。同样的口，里面可能只有 5V 和 USB 2.0，也可能是 240W、80Gbps、带两台 4K 显示器。

2. 24 个触点，为什么正反都能插

插座中间有一片"小舌头"，上下两面各 12 个触点，一共 24 个。从外往里依次是：GND、高速差分线、VBUS、CC / SBU、中间的 USB 2.0 D+ / D−。

注意：下面这张图和表都是母座（插座，设备上的口），从插口正面看过去。CC1 / CC2 也是母座的叫法。线头（公头）正看时左右是镜像的，第 5 脚也不叫 CC1/CC2，拿这张图去对线头会对反。线头的线序见 2.1。
触点作用对称吗
GND、VBUS电源，各 4 个分担电流完全对称，正反都一样
D+ / D−USB 2.0（480Mbps），也是 QC 等私有快充的握手线上下各一份，设备板上把两份连在一起，所以不管正反都通
CC1 / CC2配置通道：插入检测、判断方向、电流档位、PD 通讯不对称：线里只有一根 CC，插哪面就连到哪个 CC
TX/RX 高速线USB 3 / USB4 / 雷电 / DP两组。插反时由芯片（MUX）切换到另一组
SBU1 / SBU2DP 的 AUX 辅助通道（读显示器型号、分辨率）、模拟耳机的麦克风/地按方向切换
视频里的说法："CC 和 SBU 这两个口是最要紧的两个脚，后面讲的供电、识别、出画面全靠它。"

2.1 对着线头（公头）看的线序

线头里没有舌片，触点长在金属壳的上下内壁上，插进去时夹住母座的舌片。插入时公头 A1 对母座 A1，两者是面对面的，所以正对着线头看，A 排变成从左到右 A12 → A1，B 排是 B1 → B12，和上面母座图左右相反。

下表的 24 / 16 / 12 / 6 脚说的都是母座（座子）的规格。

座子保留的脚阿甘视频里的例子
24 脚全部"满针脚的 Type-C 好是好，但用的其实并不多"，很多产品不需要高速传输
16 脚去掉 8 个高速脚（TX/RX 两组）除了不支持 USB 3.0 高速，功能和 24 脚一样

5. 谁上拉谁供电：手机给 U 盘供电、两台手机对插

5.1 角色名称：DFP、UFP、DRP

名称全称可以理解成充电领域里（阿甘视频的例子）
DFPDownstream Facing Port，下行端口Host，对外提供电源和数据供电端。充电器是典型的 DFP
UFPUpstream Facing Port，上行端口Device，从 VBUS 取电并提供数据受电端。儿童电话手表是典型的 UFP
DRPDual Role Port，双角色端口能当 DFP 也能当 UFP，可以动态切换供电受电二合一。快充充电宝是典型的 DRP，既可以充电又可以放电

严格说 DFP/UFP 是数据角色，Source/Sink 是电源角色，规范里两者可以分开（比如笔记本给显示器"数据下行"，却从显示器取电）。日常充电场景里两者一般一致，视频也是这样讲的。

5.2 四种 CC 识别模式，和 DRP 的来回切换

组合结果
Source → Sink确定：充电器给手表充电
Source → DRPDRP 切到 Sink：充电器给充电宝充电
DRP → SinkDRP 切到 Source：充电宝给手表充电，手机给 U 盘供电
DRP → DRP看时机，比较随机：两台充电宝、两台手机对插
为什么充电宝 + 手机，总是充电宝给手机充？两者都是 DRP，按说也是随机的。但充电宝里的协议控制芯片会让它更偏向当供电端：比如 Source 状态保持的时间更长（视频举例 200ms），或者用规范里的 Try.SRC 机制（识别到对方也是 DRP 时，主动再尝试当一次 Source）。手机则倾向 Try.SNK。所以实际使用中充电宝基本"永远"是供电端，而不是手机给充电宝充电。

6. PD 快充：清单、请求、升压；PPS；PD 3.1 EPR

要 5V 以上的电压就要用 USB Power Delivery（PD）。它同样走 CC 那一根线，两头各有一颗协议芯片在上面收发报文。

充电器上的瓦数只是上限，实际取多少由设备决定。100W 的头给手机充，手机只要 20W 就是 20W，不会把手机充坏。
反过来不行：拿 20W 的手机头去充笔记本，清单里只有 5V 和 9V。有的笔记本只认 20V，直接不充；有的能凑合，提示"充电缓慢"（还可能边用边掉电）。

PPS 可调电压

清单里还可以有一种可调档（APDO），叫 PPS：从 3.3V 起，每步 20mV，电流也能设上限。手机一边充电，一边让充电器跟着电池电压微调，手机里只需要一个效率很高的电荷泵把电压对半分，压降电路损耗小、发热也小。三星的超级快充就靠 PPS；PD 3.2 还新加了 AVS（9~20V，100mV 一步）。

8. 私有快充协议、UFCS、多口充电器

多口充电器的功率分配

  • 总功率是几个口共用的。外壳上印的最大瓦数，一般指只插一个口的时候。两个口都插就按厂家定好的方案分，比如 65W 头变成 45W + 15W。
  • 插上或拔掉第二个设备时，很多充电器要重新分配功率，输出会断一下再恢复（协议芯片关一下 VBUS 让设备重新握手）。
  • 给开发板、路由器这类没有电池的东西供电时，旁边一插手机，板子就自动重启了。

11. 各种情况逐个分析（重点）

供电数据视频其他

案例 1 供电小风扇、台灯：A-C 线能充，C-C 线和快充头都不充

现象：用 USB-A 转 Type-C 的线能充；换成双头 Type-C 线，插什么快充头都没反应。这正是第一个视频（小功率电器为什么不支持 C2C 充电）讲的情况。

原因：Type-C 充电器要先看到 CC 上的 5.1kΩ 下拉才送电（第 4 节）。很多便宜的小风扇、小台灯为了省两颗电阻，CC 没接 Rd（甚至用 6 脚座只焊了电源脚）。A-C 线里有 56kΩ 上拉，A 口的 5V 一直在，所以能用。

阿甘视频的实测：手电筒、小风扇用 A 口充电器 + A-C 线正常充电；换 C 口充电器（或充电宝的 C 口）+ C-C 线，测试仪上没有任何电流；拆开手电筒，板上只引出了 VBUS、GND、D+、D−，"压根就没有 CC 下拉电阻"。另一块只保留 GND、VBUS、CC1、CC2、两颗 5.1kΩ 接地的小板，插上 C 口充电器或充电宝立刻被识别并供电。

怎么办：①只能用 A-C 线充，换什么快充头都没用；②会焊的话，在 CC1、CC2 到 GND 各补一颗 5.1kΩ（0402/0603），就能用 C-C 线；③少数有智能识别的充电器会在 CC 没下拉时也短暂输出，但不能指望。

案例 2 供电自己画的板子：普通 C-C 线能用，换"好线"（5A / e-marker）反而不出电

原因：CC1 和 CC2 连在一起共用一颗 Rd（第 7.2 节）。e-marker 线的 Ra 被并进来，充电器量到的阻值既不像 Rd 也不像 Ra，判断失败。改法：CC1、CC2 各自一颗 5.1kΩ 到地，不能合并。

案例 3 供电小功率手机头充笔记本：不充，或提示"充电缓慢"

原因：20W 头的清单里只有 5V、9V。笔记本一般需要 20V，有的只认 20V 直接拒绝；有的接受 9V 或 15V，但功率不够，边用边掉电。判断：看充电头标签上的输出档位有没有 20V。建议：笔记本至少用 45~65W、带 20V 档的 PD 充电器。

案例 4 供电100W 充电器 + 100W 笔记本，只能跑到 60W

原因：线是普通 3A 线，没有 e-marker，充电器按 3A 算，20V × 3A = 60W（第 7.1 节）。改法：换印着 100W 或 240W 的 5A 线。用 PD 测试仪能读出线里的 e-marker 信息。

案例 5 供电140W 充电器给 140W 电脑，只有 100W

两种可能：①标准 PD 3.1（28V）：线不是 240W EPR 线，充电器不升 28V；②私有 20V 7A 那种 140W：充电器、线、电脑不是同一家原装，私有协议对不上，退回标准 PD 100W。

案例 6 供电手机号称 120W，用别家充电器很慢

原因：120W 是手机厂的私有协议（多走 D+/D−），要原装头 + 原装线（电流可能超过 5A）。别家充电器能对上的往往只有 PD 或 UFCS，功率是原装的几分之一；都对不上就是 5V 慢充。建议：看手机和充电器是否都标 UFCS，或者至少都支持 PD PPS。

案例 7 供电开发板、路由器用多口充电器供电，旁边插手机就重启

原因：插拔第二个设备时，多口充电器重新分配功率，输出断一下再恢复（第 8 节）。没有电池的设备直接掉电。改法：这类设备用单口充电器或独立电源；或者在板上加够大的储能电容、用不会断电的电源。

案例 8 供电两台手机 / 两台充电宝对插，充电方向不确定

原因：两台都是 DRP，插上时谁先停在上拉谁就供电（第 5.2 节），阿甘视频里两台充电宝对插，每次插拔电流方向都可能变。充电宝 + 手机则基本固定是充电宝供电（Try.SRC）。部分手机在通知栏或设置里能切换"为对方充电"，支持 PD 的还能通过 PR_Swap 交换角色。

案例 9 数据拷文件很慢，像 USB 2.0

排查顺序：①线是不是充电线（只有 D+/D−，最常见）；②设备口后面是不是只接了 USB 2.0（不少手机标准版就这样）；③移动硬盘盒/U 盘本身的速度；④插的是电脑哪个口。判断：换一根印着 10Gbps 以上的全功能线，再换口试；在电脑设备管理器或系统信息里能看到当前连接速度。

案例 10 视频接显示器不亮

视频里说：一般就两种情况。

另外：显示器那头要是 Type-C 输入或者用 C 转 HDMI/DP 转接头；口旁边有 D 形 DP 标或闪电标的才能出画面；用转接头接 HDMI 时转接头里还有一颗 DP 转 HDMI 芯片，它本身也会限制分辨率。

案例 11 视频扩展坞接 4K 屏，鼠标一卡一卡

原因：扩展坞把四对线分成 2 对 DP + 2 对 USB 3，电脑口如果只是 DP 1.2，2 对只能跑 4K 30Hz（第 10 节）。改法：换支持 DP 1.4 的电脑口/扩展坞；或在扩展坞设置里选"高分辨率模式"（四对全给 DP，USB 降为 2.0）；或用雷电/USB4 扩展坞。

案例 12 数据视频同样写着 USB4，两个口能力差一截；雷电线只跑 20G

原因：USB4 最低只要求 20Gbps，其他是选配；雷电 3 无源长线只有 20G。判断：看口旁边的闪电标、说明书接口表，买线看印的速度（40Gbps / 80Gbps）和长度（无源 40G 一般 ≤0.8m）。

案例 13 其他Type-C 耳机转接头换一台手机就没声音

转接头有两种：模拟的把左右声道直接接在 USB 2.0 那对线上（麦克风走 SBU），要手机口支持"音频附件模式"才有声音；数字的插头里带一颗解码芯片（DAC），手机把它当 USB 声卡用。有的手机只认数字的，所以同一个转接头换台手机可能没声。

补充：模拟耳机靠 CC1、CC2 都接 Ra（都下拉到约 1kΩ 以下）让手机识别成"音频附件"。

案例 14 供电自己做的 12V 板子，有的充电器能用，有的不行

原因：12V 不在 PD 的 5/9/15/20V 四档固定电压里，有的充电器清单里有 12V，有的没有。改法：板子按 9V 或 15V 设计，或要 12V 时取 15V 再用 Buck 降压；同时想好拿不到时怎么办（比如退回 5V 时板子是否能安全待机）。

案例 15 供电PD 诱骗板上电瞬间烧了后级芯片

原因：VBUS 先是 5V，协商完才升到 20V。如果取电芯片没有输出开关，后级电路会先吃 5V 再吃 20V；协商失败又会停在 5V。后级必须能承受整个过程。改法：选择带 MOS 控制、电压到位才打开输出的取电芯片，并查规格书确认它的上电时序。

13. 自己做板子从 Type-C 取电

两点注意（视频里也强调了）：①12V 不在四档固定电压里，充电器不一定有；②上电时 VBUS 先是 5V，协商完才升压，后级电路要扛得住这个过程，具体行为每颗芯片不一样，要查规格书。另外：取 20V 时 VBUS 上的电容、TVS、后级芯片耐压都要按 20V 以上选；有电池的设备做取电要考虑电源路径管理。

14. 怎么查口和线、买线怎么挑

查接口

  • 先看口旁边的图标：闪电是雷电；D 字形的标是能出 DP；带 SS 或速度数字的是 USB 3 以上。
  • 没有图标就翻说明书里的接口表。供电、数据速度、视频是分开写的，三项都要看。

查线

  • 看线身或包装印的字：瓦数和速度是分开标的。只写瓦数不写速度，基本就是充电线。
  • 手边有带 PD 功能的 USB 测试仪（如 ChargerLAB POWER-Z、FNIRSI FNB58 类），可以直接读线里的 e-marker：电流、耐压、速度都能读出来；还能看充电器的 PDO 清单、实时电压电流。

买线建议：按用途分开买

用途怎么选
只充电看瓦数。60W 的可以不带芯片；100W 和 240W 的都带 e-marker
